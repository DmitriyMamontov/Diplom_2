Мамонтов Дмитрий, 20я когорта, 2 часть дипломного проекта.
В рамках данной части дипломного проекта мне удалось создать автотесты
для веб-сайта: https://stellarburgers.nomoreparties.site/
api документация: https://code.s3.yandex.net/qa-automation-engineer/python-full/diploma/api-documentation.pdf?etag=3403196b527ca03259bfd0cb41163a89
также составлен итоговый allure отчет по проведенным тестам.

Были созданы авто тесты на ручки для:

Создание пользователя:
- создать уникального пользователя;
- создать пользователя, который уже зарегистрирован;
- создать пользователя и не заполнить обязательное поле пароль.
- создать пользователя и не заполнить обязательное поле email.
- создать пользователя и не заполнить обязательное поле имя.

Логин пользователя:
- логин под существующим пользователем,
- логин с неверной почтой и паролем.
- логин с неверным паролем.

Изменение данных пользователя:
- с авторизацией,
  - можно изменить почту,
  - можно изменить имя,
- без авторизации,
  - ошибка при изменении почты,
  - ошибка при изменении имени,

Создание заказа:
- с авторизацией и ингредиентами,
- без авторизации,
- без ингредиентов,
- с неверным хешем ингредиентов.

Получение заказов конкретного пользователя:
- авторизованный пользователь,
- неавторизованный пользователь.
Создан отдельный репозиторий для тестов API.
Подключены библиотеки: pytest, requests и allure-pytest.

В тестах предусмотрены проверки как для статус кодов ответов, так и тела ответа.
В фикстурах к тестам предусмотрено автоудаление тестовых данных после проведения тестирования.
